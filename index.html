UI design styles

Every entry renders a live specimen, lists the traits that make it that style, and hands you the tokens and CSS to paste somewhere else.

/

Style specimens are drawn with the real technique each style is made of — no screenshots, no images, so what you copy is what renders. The real-world examples section is different by design: those are photographs of live sites, captured from the page itself by this repo's tooling, with the link out as the source of truth. The catalog chrome keeps to one neutral type ramp and a hairline-only surface treatment; the entries inside it deliberately break those rules, because breaking them is the entry.

Style names describe visual conventions in broad use; origins are noted with each entry. Sources are listed per entry where a specific public write-up informed the description. Real sites are named and linked to their owners' pages, and are shown only as examples of the style.
